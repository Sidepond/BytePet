# 마멀레이드 · 새로운 PixelLab 고양이

[미리보기](./preview.html)를 브라우저에서 연다. 왼쪽은 새 디자인의 기준 자세, 오른쪽은 생성한 애니메이션이다. 대기/잠자기, 실제 크기/3배 확대, 일시 정지와 프레임 선택을 제공한다. 이미지가 내장되어 인터넷 없이 동작한다. 실제 앱의 기본 캐릭터에는 아직 적용하지 않았다.

## 디자인 방향

기존 코드 캐릭터의 이미지·팔레트·얼굴을 입력하지 않았다. PixelLab Pixen에 텍스트만 전달해 둥근 볼, 작은 몸통, 주황 줄무늬와 청록색 스카프가 있는 새로운 고양이를 만들었다. 잠든 자세와 애니메이션은 이 **새로 생성한 디자인**만 참조한다.

대기는 눈깜박임과 귀·꼬리·상체의 움직임, 잠자기는 편안한 호흡을 요청했다. 생성된 전체 프레임을 순서대로 재생하며 얼굴이나 몸 일부를 정지 그림으로 덮지 않는다. 기존 24×24 그림의 위치나 1픽셀 호흡 제한을 적용하지 않는다.

## 규격

| 항목 | 값 |
| --- | --- |
| 첫 디자인 | 텍스트로 생성한 32×32 PNG |
| 애니메이션 작업 캔버스 | 여백을 추가한 48×48 PNG |
| 화면 프레임 | 96×96, 모든 자세에 동일한 2배 정수 확대 |
| 시트 | 384×192, 4열×2행, 동작당 8프레임 |
| 바닥선 | 논리 y=45, 화면 y=90 |
| 정렬 | 프레임별 바닥 위치만 평행 이동, 좌우 좌표 유지 |
| 픽셀 처리 | nearest-neighbor, 프레임별 확대/축소와 부분 합성 없음 |

앉은 자세보다 누운 자세는 가로 공간이 필요하다. 첫 32×32 잠든 자세는 얼굴이 작아져서 제외했고, 새 디자인을 여백 있는 48×48 캔버스에 놓은 뒤 같은 크기의 얼굴과 몸을 유지하도록 잠든 자세를 다시 생성했다. 캔버스를 여백으로 늘릴 때 원본 픽셀 크기는 바꾸지 않았다.

API가 반환한 입력 자세와 8개 프레임 중 시작 자세로 돌아오는 마지막 장을 제외한 0~7번을 그대로 사용한다. 두 동작 모두 서로 다른 8프레임이며, 대기는 2.22초, 잠자기는 3.6초 주기다. 자연스러운 호흡에 따른 윤곽 변화는 허용한다.

API의 마지막 장은 시작 그림과 완전히 같은 픽셀은 아니다. 대기는 45픽셀, 잠자기는 43픽셀에 차이가 남았다. 따라서 동일성 검사는 기록으로 남기고, 실제 재생의 7→0 전환 차이가 내부 프레임 사이의 최대 변화보다 작은지 별도로 검사한다. 확대된 프레임도 육안으로 확인했다. 이는 지각적인 자연스러움을 완전히 보장하는 지표는 아니며 미리보기에서 확인할 수 있다.

## 생성 기록과 재현

실제 프롬프트와 입력은 `*-request.json`, API 응답과 사용량은 `*-response.json` 및 `*-job.json`, 가공하지 않은 이미지는 `source/`에 있다. `source/sleep-pose/`는 제외한 첫 잠든 자세, `source/sleep-pose-wide/`는 다시 생성한 자세다. `references/`는 애니메이션 입력이며, [대기 원본](./raw-idle.png)과 [잠자기 원본](./raw-sleeping.png)은 API가 반환한 9장의 확대 보기다.

이번 팩은 디자인 1회, 잠든 자세 2회, 애니메이션 2회로 총 5회 생성했다. 각 API 응답은 `generations: 1`을 기록했으며 금액은 제공하지 않았다.

```sh
# 저장된 결과로 시트·미리보기 재구성 및 검증 (API 호출 없음)
npm run build:marmalade

# 완료/진행 중인 작업 가져오기 (새 생성 없음)
npm run sprites:marmalade -- poll idle
npm run sprites:marmalade -- poll sleeping
```

새 팩을 같은 순서로 만들려면 `design` 생성 → `build:marmalade -- prepare-design` → `sleep-pose-wide` 생성 → `build:marmalade -- prepare` → `idle`, `sleeping` 생성 → `build:marmalade` 순서다. `sprites:marmalade -- generate <단계>`만 API 생성을 요청한다. 현재 팩의 작업 기록이 있으면 중복 요청을 거부한다. POST 전에 기록을 예약해 타임아웃이 발생해도 자동으로 재과금하지 않는다. 키는 Git에서 제외한 `.env.local`의 `PIXELLAB_API_KEY`를 사용한다.

`atlas.json`에는 크기·바닥·재생 시간·원본 프레임 인덱스와 위치 보정을 기록한다. `validation.json`에는 크기, 투명 여백, 잘림, 반복 연결, 정수 확대와 UI 재생·정지·프레임 선택·동작 줄이기·작은 화면 검증 결과를 기록한다. 빌드 도구는 별도의 임시 Electron 프로필을 사용한다.

API: [공식 문서](https://api.pixellab.ai/v2/docs)의 `/create-image-pixen`, `/edit-image-pixen`, `/animate-with-text-v3`.
