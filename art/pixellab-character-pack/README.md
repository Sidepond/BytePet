# BytePet · PixelLab 캐릭터 모음

[전체 미리보기](./preview.html)에서 여섯 캐릭터를 동시에 볼 수 있다. 대기/잠자기, 실제 크기/2배 확대, 일시 정지와 다음 프레임을 지원한다. 각 카드의 **프레임 자세히 보기**는 캐릭터별 기준 자세와 애니메이션을 비교하는 화면을 연다. HTML에 이미지를 내장해 오프라인으로 동작한다.

현재 앱의 캐릭터 렌더러와 설정 미리보기에 6종 모두 적용했다. `npm run sync:characters`로 PNG 12개와 재생 시간을 앱의 `desktop/` 경로에 복사한다. 대기·잠자기는 이 이미지로 재생하고, 먹기·처리 중·공격·성공/실패는 동일 외형에 작은 픽셀 효과를 표시한다. 그루밍은 이미지 제작 전까지 자동 재생하지 않는다. 전용 반응 이미지와 눕고 일어나는 전환은 다음 제작 범위다.

| 캐릭터 | 종류 | 구분 요소 |
| --- | --- | --- |
| 마멀레이드 | 치즈 고양이 | 주황 줄무늬, 둥근 볼, 청록색 스카프 — 승인된 시안 유지 |
| 오레오 | 턱시도 고양이 | 흰 얼굴 무늬·양말발, 초록 눈, 작은 모자와 빨간 나비넥타이 |
| 루나 | 까망 고양이 | 짙은 털, 호박색 눈, 보라색 스카프와 갈고리 모양 꼬리 |

새 외형은 기존 코드 그림 없이 PixelLab의 같은 모델과 공통 스타일 지시로 생성했다. 각자 새로 생성한 외형을 참조해 잠든 자세와 모션을 만들었다. 색만 교체한 스프라이트가 아니며 귀·얼굴·체형·꼬리도 다르다.

## 공통 규격과 검증

- 첫 디자인 32×32 PNG → 투명 여백을 더한 48×48 애니메이션 입력. 잠든 자세는 가로 공간을 확보한 48×48로 생성.
- 화면 프레임 96×96. 원본 픽셀을 동일하게 2배 확대하며 프레임별 크기 맞춤이나 얼굴·몸 부분 합성을 하지 않음.
- 각 동작은 4열×2행의 384×192 투명 PNG, 8프레임. 대기 2.22초, 잠자기 3.6초.
- 바닥선 y=90. 바닥 정렬은 수직 평행 이동만 사용하며 잘린 픽셀이 없는지 검사.
- 첫 프레임과 API의 마지막 프레임은 세부 픽셀이 다를 수 있다. 실제 마지막→처음 전환의 차이가 내부 전환의 최대 변화보다 크지 않은지 검사하고 확대 화면을 확인한다. 이 수치는 지각적인 자연스러움을 완전히 보장하지 않는다.
- 오레오의 대기는 닫힌 눈 자세 하나를 생략하고 0·1·2·3·4·5·7·8번을 사용해 마지막 눈 열기와 복귀 자세를 포함했다. 선택한 원본 인덱스는 프로필과 atlas에 기록한다.
- 비스킷의 잠자기에는 API가 추가한 떠다니는 기호가 있어, 캐릭터와 연결되지 않고 머리 위로 솟은 작은 픽셀 덩어리만 제거했다. 몸을 이루는 연결된 픽셀 덩어리의 10%보다 작은 것만 대상으로 하며, 실제 원본에서 몸·귀·꼬리·발이 한 덩어리임을 확인했다. 캐릭터 픽셀은 그대로 유지하고 제거한 픽셀 수는 atlas에 기록한다. API 원본은 수정하지 않았다.
- 캐릭터별 `atlas.json`, `validation.json`에 프레임 인덱스·위치 보정·측정값과 검증 결과를 남김.
- 모음 화면은 6종의 로딩·재생·일시 정지·프레임 이동·동작 전환·실제 크기·상세 링크·동작 줄이기·좁은 화면을 검사.

## 파일과 실행

각 팩은 `art/<id>-pixellab/`에 있다. ID는 `marmalade`, `tuxedo`, `midnight`, `shiba`, `retriever`, `corgi`이다. `idle.png`와 `sleeping.png`가 시트이며, `source/`는 수정하지 않은 생성 원본, `references/`는 여백을 맞춘 애니메이션 입력이다. 요청·응답·작업 JSON에 실제 프롬프트와 사용량을 보관한다. API 키는 Git에서 제외된 `.env.local`에만 둔다.

새 5종에는 디자인 5회, 잠든 자세 5회, 애니메이션 10회로 총 20회의 생성이 완료됐다. API가 보고한 사용량 합계는 `20 generations`이며 금액은 제공되지 않았다. 단계별 사용량은 `usage.json`에 정리했다. 마멀레이드의 두 시트는 승인된 파일과 SHA-256 해시가 동일하다.

```sh
# API 호출 없이 특정 캐릭터의 시트·비교 화면 재구성 및 검증
npm run build:character -- build tuxedo

# API 호출 없이 전체 갤러리 재구성 및 검증
npm run build:characters

# API 호출 없이 첫 디자인 모음 PNG 만들기
npm run build:characters -- poses
```

생성 스크립트는 `scripts/pixellab-character-profiles.mjs`의 외형·이름·종류·시드를 사용한다. `npm run sprites:pack`은 새 5종을 순서대로 처리한다. 완료한 작업은 재생성하지 않고, 진행 중인 작업은 이어서 조회한다. 누락된 단계만 유료 API 생성을 요청한다. 승인된 마멀레이드는 기본 생성 대상에서 제외한다.

서버가 명시적으로 HTTP 429를 반환한 경우에만 기록을 보존한 뒤 `retry-rejected`로 재제출할 수 있다. 응답을 못 받은 POST나 알 수 없는 실패는 자동 재요청하지 않는다. 이번 생성 중 계정 동시 작업 제한을 확인해 이후 순차 처리로 전환했다.

공식 API: [PixelLab 문서](https://api.pixellab.ai/v2/docs)의 `/create-image-pixen`, `/edit-image-pixen`, `/animate-with-text-v3`.
