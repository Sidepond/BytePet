# BytePet · PixelLab 캐릭터 모음

[전체 미리보기](./preview.html)에서 여섯 캐릭터를 동시에 볼 수 있다. 대기/잠자기/먹기/들기, 원본 크기/2배 확대, 일시 정지와 다음 프레임을 지원한다. 각 카드의 **프레임 자세히 보기**는 캐릭터별 기준 자세와 애니메이션을 비교하는 화면을 연다. HTML에 이미지를 내장해 오프라인으로 동작한다.

대기·잠자기·먹기는 앱의 6종 모두에 적용했다. 들기는 현재 고양이 3종까지 완료했으며, 강아지 3종의 들기는 [후속 작업으로 보류](#dog-dragging-todo)했다. 미리보기의 들기에서 준비 중인 캐릭터는 기존 대기 이미지를 표시한다. `npm run sync:characters`로 PNG 21개와 재생 시간을 앱의 `desktop/` 경로에 복사한다. 대기·잠자기·먹기는 이 이미지로 재생한다. 먹이 저장 후 1.8초 동안 한입 먹고 씹는 모션을 보여주며, 변환 처리 중에는 먹기 모션을 빠르게 재생한다. 공격·성공/실패는 동일 외형에 작은 픽셀 효과를 표시한다. 그루밍은 이미지 제작 전까지 자동 재생하지 않는다. 공격·성공/실패 전용 이미지와 눕고 일어나는 전환은 다음 제작 범위다.

| 캐릭터 | 종류 | 구분 요소 |
| --- | --- | --- |
| 마멀레이드 | 치즈 고양이 | 주황 줄무늬, 둥근 볼, 청록색 스카프 — 승인된 시안 유지 |
| 오레오 | 턱시도 고양이 | 흰 얼굴 무늬·양말발, 초록 눈, 작은 모자와 빨간 나비넥타이 |
| 루나 | 까망 고양이 | 짙은 털, 호박색 눈, 보라색 스카프와 갈고리 모양 꼬리 |
| 모찌 | 시바 | 크림색 볼, 세운 귀, 말린 꼬리와 초록색 스카프 |
| 허니 | 리트리버 | 늘어진 귀, 넓은 주둥이, 황금색 털과 하늘색 스카프 |
| 비스킷 | 코기 | 큰 귀, 짧은 다리, 흰 이마 무늬와 자주색 스카프 |

새 외형은 기존 코드 그림 없이 PixelLab의 같은 모델과 공통 스타일 지시로 생성했다. 각자 새로 생성한 외형을 참조해 잠든 자세와 모션을 만들었다. 색만 교체한 스프라이트가 아니며 귀·얼굴·체형·꼬리도 다르다.

## 후속 작업: 강아지 3종 들기 모션 (보류)

2026-10-16 사용자 결정으로 현재 작업은 고양이 3종까지 마무리하고, 강아지 3종의 들기는 나중에 진행한다. 대기·잠자기·먹기는 강아지도 모두 완료되어 있다. 현재 강아지를 끌 때는 기존 대기 이미지를 사용한다.

- [ ] 모찌 — 시바 (`shiba`): 들기 자세·8프레임 애니메이션 생성
- [ ] 허니 — 리트리버 (`retriever`): 들기 자세·8프레임 애니메이션 생성
- [ ] 비스킷 — 코기 (`corgi`): 들기 자세·8프레임 애니메이션 생성
- [ ] 갤러리·앱 에셋 반영, 모션 확인 및 회귀 검증

중단 지점은 모찌의 첫 들기 자세 요청이다. PixelLab 크레딧 부족으로 HTTP 402가 반환됐으며, 강아지의 두 생성 단계(`drag-pose`, `dragging`)는 모두 미완료다. 남은 기본 생성은 총 6회다. 고양이 원본과 완료 기록은 보존한다.

추후 이 작업을 재개하기로 할 때 PixelLab 크레딧과 `.env.local`의 `PIXELLAB_API_KEY`를 확인한 뒤 아래 순서로 실행한다. 첫 명령만 유료 API를 사용하며, 완료된 원본은 재사용하고 누락된 단계부터 이어간다.

```sh
npm run sprites:dragging -- shiba retriever corgi
npm run build:characters
npm run sync:characters
npm test
npm run test:desktop
npm run package:mac
npm run test:package
```

완료 시 96×96 프레임·112×112 표시 크기를 유지하고, 머리의 불필요한 흔들림과 픽셀 잘림, 반복 연결, 놓을 때 착지, 취소·숨기기 복구, 동작 줄이기를 확인한다. 기존 대기·잠자기·먹기 이미지는 유지한다. 앱 PNG는 21개에서 24개, 전체 프레임은 168개에서 192개가 된다. `dragging-usage.json`과 이 문서의 수치·완료 상태를 갱신하고 위 항목을 체크한다.

## 공통 규격과 검증

- 첫 디자인 32×32 PNG → 투명 여백을 더한 48×48 애니메이션 입력. 잠든 자세는 가로 공간을 확보한 48×48로 생성.
- 화면 프레임 96×96. 원본 픽셀을 동일하게 2배 확대하며 프레임별 크기 맞춤이나 얼굴·몸 부분 합성을 하지 않음.
- 각 동작은 4열×2행의 384×192 투명 PNG, 8프레임. 대기 2.22초, 잠자기 3.6초, 먹기 1.8초, 들기 1.44초. 앱 표시 크기는 112×112px.
- 바닥선 y=90. 지상 동작은 발을 정렬하며, 들기는 첫 프레임의 발을 y=82에 두고 머리 높이를 맞춰 몸 전체의 상하 흔들림을 줄인다. 각 프레임 전체를 수직으로만 이동하고 잘린 픽셀이 없는지 검사한다. 들기에서 발 위치는 자유롭게 움직일 수 있다.
- 착지는 앱에서 기본 자세를 0.3초 동안 수직 이동해 표현한다. 프레임별 확대·축소나 몸 부분 합성은 하지 않는다.
- 첫 프레임과 API의 마지막 프레임은 세부 픽셀이 다를 수 있다. 실제 마지막→처음 전환의 차이가 내부 전환의 최대 변화보다 크지 않은지 검사하고 확대 화면을 확인한다. 이 수치는 지각적인 자연스러움을 완전히 보장하지 않는다.
- 오레오의 대기는 닫힌 눈 자세 하나를 생략하고 0·1·2·3·4·5·7·8번을 사용해 마지막 눈 열기와 복귀 자세를 포함했다. 선택한 원본 인덱스는 프로필과 atlas에 기록한다.
- 비스킷의 잠자기에는 API가 추가한 떠다니는 기호가 있어, 캐릭터와 연결되지 않고 머리 위로 솟은 작은 픽셀 덩어리만 제거했다. 몸을 이루는 연결된 픽셀 덩어리의 10%보다 작은 것만 대상으로 하며, 실제 원본에서 몸·귀·꼬리·발이 한 덩어리임을 확인했다. 캐릭터 픽셀은 그대로 유지하고 제거한 픽셀 수는 atlas에 기록한다. API 원본은 수정하지 않았다.
- 캐릭터별 `atlas.json`, `validation.json`에 프레임 인덱스·위치 보정·측정값과 검증 결과를 남김.
- 모음 화면은 6종의 로딩·재생·일시 정지·프레임 이동·동작 전환·실제 크기·상세 링크·동작 줄이기·좁은 화면을 검사.

## 파일과 실행

각 팩은 `art/<id>-pixellab/`에 있다. ID는 `marmalade`, `tuxedo`, `midnight`, `shiba`, `retriever`, `corgi`이다. `idle.png`·`sleeping.png`·`eating.png`·`dragging.png`가 시트이며, `source/`는 수정하지 않은 생성 원본, `references/`는 여백을 맞춘 애니메이션 입력이다. 요청·응답·작업 JSON에 실제 프롬프트와 사용량을 보관한다. API 키는 Git에서 제외된 `.env.local`에만 둔다.

새 5종에는 디자인 5회, 잠든 자세 5회, 애니메이션 10회로 총 20회의 생성이 완료됐다. API가 보고한 사용량 합계는 `20 generations`이며 금액은 제공되지 않았다. 단계별 사용량은 `usage.json`에 정리했다. 들기 자세·애니메이션은 고양이 3종까지 생성 6회가 완료됐고 `dragging-usage.json`에 기록했다. 강아지 생성은 잔량 0으로 중단됐다. 강아지 작업은 보류했으며, 재개 절차는 [후속 작업](#dog-dragging-todo)에 기록했다. 대기·잠자기 시트는 승인된 파일과 SHA-256 해시가 동일하다. 이후 먹기 애니메이션 6회를 추가 생성했으며, 추가 사용량 `6 generations`는 `eating-usage.json`에 기록했다.

```sh
# 누락된 들기 자세와 모션을 순차 생성하고 검증 (유료 API)
npm run sprites:dragging

# 누락된 먹기 모션만 순차 생성하고 시트·미리보기 검증 (유료 API)
npm run sprites:eating

# API 호출 없이 특정 캐릭터의 시트·비교 화면 재구성 및 검증
npm run build:character -- build tuxedo

# API 호출 없이 전체 갤러리 재구성 및 검증
npm run build:characters

# API 호출 없이 첫 디자인 모음 PNG 만들기
npm run build:characters -- poses
```

생성 스크립트는 `scripts/pixellab-character-profiles.mjs`의 외형·이름·종류·시드를 사용한다. `npm run sprites:pack`은 새 5종을 순서대로 처리한다. 완료한 작업은 재생성하지 않고, 진행 중인 작업은 이어서 조회한다. 누락된 단계만 유료 API 생성을 요청한다. 승인된 마멀레이드는 기본 생성 대상에서 제외한다.

서버가 명시적으로 HTTP 429를 반환한 경우 기록을 보존한 뒤 `retry-rejected`로 재제출할 수 있다. HTTP 402는 크레딧 충전 후, HTTP 422는 요청 값을 수정한 뒤 명시적으로 재제출할 수 있으며, 이미지 편집 설명은 요청 전 500자 제한을 검사한다. 응답을 못 받은 POST나 알 수 없는 실패는 자동 재요청하지 않는다. 이번 생성 중 계정 동시 작업 제한을 확인해 이후 순차 처리로 전환했다.

공식 API: [PixelLab 문서](https://api.pixellab.ai/v2/docs)의 `/create-image-pixen`, `/edit-image-pixen`, `/animate-with-text-v3`.
