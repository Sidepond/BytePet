# 치즈 고양이 이미지 스프라이트 · 첫 시안

[비교 미리보기](./preview.html)를 브라우저로 열면 서버나 인터넷 연결 없이 동작한다. 기존 코드 그림과 PNG 스프라이트를 같은 표시 크기로 비교하고, 대기/잠자기 선택, 3배 확대, 바닥선 표시, 일시 정지, 프레임 선택을 사용할 수 있다. 운영체제의 동작 줄이기를 켰다면 정지 상태로 시작한다.

실제 펫의 기본 렌더러는 바꾸지 않은 실험용 팩이다. 먹기·그루밍·성공·실패·공격과 서기↔눕기 전환 프레임은 아직 만들지 않았다. 외형과 두 동작의 방향을 확인한 다음 전체 동작을 같은 이미지 스타일로 확장한다.

## 고정 규격

| 항목 | 값 |
| --- | --- |
| 한 프레임 | 96×96px, RGBA PNG |
| 한 동작 시트 | 4열×2행, 384×192px |
| 읽는 순서 | 왼쪽→오른쪽, 위→아래, 총 8칸 |
| 화면 표시 크기 | 96×96 CSS px |
| 기준점 | 캔버스 중앙 x=48, 바닥선 y=92 |
| 확대 비율 | 두 동작의 모든 프레임에 동일한 비율 적용 |
| 정렬 | 목걸이 중심과 바닥으로 평행 이동. 동작별 전체 윤곽을 중앙에 배치 |
| 여백 | 프레임 경계에 닿지 않으며 발의 마지막 픽셀은 y=91 |
| 보간 | nearest-neighbor, `imageSmoothingEnabled=false` |
| 속도 | `atlas.json`의 프레임별 밀리초 배열 사용 |
| 반복 연결 | 첫 칸과 마지막 칸의 픽셀을 동일하게 구성 |

96×96은 캔버스 규격이다. 그림이 매번 캔버스 전체를 채우도록 확대하지 않는다. 누운 자세는 더 낮고 넓어지며, 호흡과 꼬리 움직임에 따른 윤곽 변화는 허용한다. 생성 원본의 작은 선·무늬 차이는 남아 있어, 확대 보기로 검토할 수 있다.

## 파일 및 재생성

- `idle.png`, `sleeping.png`: 대기와 잠자기. 잠드는 전환 동작은 포함하지 않음.
- `atlas.json`: 규격, 공통 확대 비율, 재생 시간, 원본 프레임 번호, 위치 보정과 측정한 윤곽.
- `preview.html`, `preview.png`: PNG와 비교용 코드를 내장한 단일 HTML과 비교 화면 정지 이미지.
- `source/`: 내장 `image_gen`으로 생성한 원본 PNG 두 장. 수정하지 않고 보존.
- `PROMPTS.md`: 생성 도구와 사용한 프롬프트.

기본 대기는 원본 1·2·3·4·5·3·2·1번, 잠자기는 1·2·3·4·4·3·2·1번 프레임을 사용한다. 생성 원본 8장을 그대로 반복하면 마지막→처음에서 형태가 튀므로, 검토한 프레임을 왕복 순서로 배치했다. 8칸이 모두 독립적인 키프레임이라는 의미는 아니다.

프로젝트 루트에서 `npm run build:sprites`를 실행한다. 이미지 생성 API를 다시 호출하지 않고 저장한 원본을 사용한다. Electron Canvas로 동일한 비율로 정렬·축소·시트 구성하고 비교 HTML을 만든다. 프레임별 자동 크기 맞춤은 하지 않는다.

빌드 중 PNG 크기, 바닥 정렬, 안전 여백, 마지막→처음 일치, 서로 다른 프레임 존재 여부와 미리보기의 일시 정지·프레임 이동·동작 줄이기·작은 화면 레이아웃을 검사한다. 임시 프로필을 사용하므로 실행 중인 BytePet의 설정이나 입력에 접근하지 않는다.
