# BytePet 구현 현황과 후속 작업

현재 구현은 Tauri 2 / Rust / WKWebView 기반 macOS 앱이다. Electron 실행 코드와 개발 의존성은 제거했으며 기존 데이터 가져오기를 지원한다. 사용 방법은 [README](../README.md), 개발·검증 절차는 [개발 안내](development.md)에 정리한다.

## 구현한 기능

- F01–F04: 투명 펫 창, 위치 저장·복원, 픽셀 단위 클릭 투과, 집 메뉴 열기·닫기
- F05–F09: 텍스트·파일 먹이, 로컬 보관함, JWT·JSON 변환, 형식 감지, 결과 복사와 캐릭터 반응
- F10–F13: 개발 포트 조회·브라우저 열기·종료 확인, 기능별 활성화 설정
- 보관함 검색·필터·미리보기·이름 변경·휴지통·복원, 먹이/변환 분리
- 고양이 3종·강아지 3종의 대기·잠자기·먹기, 고양이 3종의 들기와 착지
- 메뉴 방향·땅 표시 설정, 가상 데스크톱 표시, 메뉴바 복구, 위치 초기화, 로그인 시 실행 설정
- Codex·Claude 구독 사용량과 고정 게이지, 위치·표시 구간·서비스 선택

## 이후 검토할 아이디어

장애 상태 알림, 모바일 QR·터널, 클립보드 도구, Mock 데이터, 컬러 도구, 추가 변환기, 명령 슬롯, 캐시 정리, 휴식 알림, 웹 체험판, 다중 펫·사용자 스킨·변환 규칙, Windows·Linux 지원.

삭제·프로세스 종료·Git 변경은 대상과 결과를 분명히 보여준다. 기능을 끄면 해당 타이머·감시·조회가 중지되는지 검증한다. 외부 터널과 API 연결은 기능별로 네트워크 사용 범위를 정의한다. 성능·용량은 런타임과 OS를 명시해 실측한다.
