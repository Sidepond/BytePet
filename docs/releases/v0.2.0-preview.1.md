## BytePet의 첫 Tauri 미리보기

> 개발 중인 미리보기 버전입니다. 기존 Electron 버전과 구분해 설치되며, 정식 안정 버전은 아닙니다.

BytePet의 데스크톱 실행 구조를 **Electron에서 Tauri 2 + Rust + macOS WKWebView로 이전**했습니다. 익숙한 캐릭터와 집 모양 메뉴를 유지하면서 앱에 포함되는 런타임 크기를 크게 줄였습니다.

### 주요 변경 사항

- 캐릭터 6종과 기존 잠자기·먹기·지원 캐릭터의 드래그 모션을 이전했습니다.
- 먹이 보관함, 텍스트·파일·사진 저장, 검색, 미리보기, 이름 변경, 휴지통·복원을 지원합니다.
- JSON/JWT 변환, 개발 포트 조회·브라우저 열기·확인 후 프로세스 종료 기능을 이전했습니다.
- Codex·Claude 사용량 패널과 게이지를 지원합니다. 게이지가 캐릭터나 메뉴 뒤로 가려지지 않도록 창 표시 순서를 조정했습니다.
- 땅 표시, 메뉴 방향, 캐릭터 선택, 위치 복원, 트레이, 로그인 시 자동 실행 설정을 이전했습니다.
- 파일은 한 번에 하나씩 바이너리로 전송해 Base64 변환에 따른 추가 메모리 사용을 줄였습니다.

### 다운로드 및 설치

1. 아래 Assets에서 **`BytePet-Tauri-0.2.0-preview.1-arm64.dmg`**를 다운로드하세요.
2. DMG를 열고 **BytePet Tauri Preview**를 Applications로 옮기세요.
3. Applications에서 앱을 실행하세요.

이번 파일은 **Apple Silicon Mac용**입니다. macOS 12 이상을 대상으로 하며, 로그인 시 자동 실행은 macOS 13 이상에서 지원합니다. Intel Mac용 빌드는 이번 릴리스에 포함하지 않습니다.

앱은 ad-hoc 서명된 개발 빌드이며 Apple 공증을 받지 않았습니다. macOS에서 실행을 차단하면 다운로드 출처를 확인한 뒤 시스템 설정의 **개인정보 보호 및 보안 → 확인 없이 열기**를 이용할 수 있습니다.

### 기존 버전 사용자가 알아둘 점

- 기존 Electron 앱과 저장 폴더가 다릅니다. 실행만으로 기존 데이터를 덮어쓰거나 삭제하지 않습니다.
- 기존 데이터는 `~/Library/Application Support/BytePet`, 새 버전 데이터는 `~/Library/Application Support/BytePet-Tauri`에 저장됩니다.
- 기존 설정과 보관함을 복사하려면 [데이터 가져오기 안내](https://github.com/Sidepond/BytePet/blob/v0.2.0-preview.1/docs/tauri-migration.md#저장-데이터와-기존-데이터-가져오기)를 확인하세요.
- Claude가 기존 BytePet에 연결되어 있다면 먼저 기존 앱에서 연결을 해제한 뒤 새 앱에서 다시 연결하세요.
- Codex 사용량은 ChatGPT 구독으로 로그인한 Codex CLI가 필요합니다. Claude 사용량은 상태줄을 연결하고 Claude Code에서 응답을 받은 뒤 갱신됩니다.

### 검증 및 남은 확인 사항

공유 화면 로직 테스트, Rust 테스트, 실제 WKWebView의 UI·IPC 테스트를 통과한 빌드입니다. DMG 무결성과 앱 서명도 확인합니다.

다양한 Spaces·전체 화면 앱·혼합 배율 모니터 구성과 설치 후 로그인 재실행은 추가 검증이 필요합니다. 강아지 3종의 별도 드래그 이미지 작업은 후속 업데이트로 남아 있습니다.

문제가 있다면 [Issues](https://github.com/Sidepond/BytePet/issues)에 재현 순서, 앱 버전, macOS 버전과 Mac 종류를 남겨 주세요.
