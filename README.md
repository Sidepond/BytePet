# BytePet

바탕화면에 떠 있는 픽셀 개발자 펫. 현재 구현 범위는 **F01: 투명한 항상 위 창에서 ByteCat 대기 애니메이션 재생**이다.

## 실행

Node.js 22.12.0 이상과 npm이 필요하다. 최초 검증 대상은 macOS다.

```sh
npm install
npm start
```

화면 우측 하단에 96×96px 고양이가 나타나 숨을 쉬고, 눈을 깜빡이고, 꼬리를 흔든다. 창은 128×128px이며 배경과 프레임이 투명하다. 별도 서버나 외부 네트워크 연결 없이 로컬 파일을 읽는다.

종료하려면 고양이를 우클릭해 **BytePet 종료**를 선택하거나 앱 메뉴에서 종료한다. 시스템의 동작 줄이기 설정을 사용하면 고양이는 정지 상태로 표시된다.

위치 이동·복원(F02), 투명 영역 클릭 투과(F03), 유틸리티 패널(F04)은 후속 작업이다. 현재 창의 투명 여백도 마우스 입력을 받는다. 이 구현은 Electron 기반 MVP이며 PRD의 Tauri 메모리·설치 용량 목표를 충족했다고 간주하지 않는다.

## 검증

```sh
npm test
npm run test:desktop
```

데스크톱 테스트는 실제 Electron GUI를 실행한다. 디스플레이가 있는 환경에서 실행해야 한다.
