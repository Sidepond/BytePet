# BytePet

바탕화면에 떠 있는 픽셀 개발자 펫. 현재 구현 범위는 **F01~F11: 펫 표시·이동·클릭 투과·유틸리티 패널·텍스트/파일 먹이 보관·JWT 해독·JSON 정리·입력 형식 자동 선택·결과 복사/반응·개발 포트 목록/주소 열기**이다.

## 실행

Node.js 22.12.0 이상과 npm이 필요하다. 최초 검증 대상은 macOS다.

```sh
npm install
npm start
```

화면 우측 하단에 96×96px 고양이가 나타나 숨을 쉬고, 눈을 깜빡이고, 꼬리를 흔든다. 창은 128×128px이며 배경과 프레임이 투명하다. 별도 서버나 외부 네트워크 연결 없이 로컬 파일을 읽는다.

고양이의 보이는 픽셀을 마우스 왼쪽 버튼으로 잡아 드래그하면 위치를 옮길 수 있다. 클릭 중 작은 손떨림은 이동으로 처리하지 않는다. 마지막 위치는 자동 저장되며 앱을 다시 실행하면 복원된다. 모니터 연결이나 해상도가 바뀌면 현재 화면의 작업 영역 안으로 위치를 보정한다.

창의 투명 여백과 고양이 윤곽 안팎의 완전히 투명한 픽셀에서는 뒤쪽 앱을 클릭할 수 있다. 클릭 영역은 애니메이션에 맞춰 갱신된다. 이미 드래그를 시작했거나 우클릭 메뉴가 열린 동안은 펫이 입력을 유지한다.

고양이를 클릭하면 옆에 유틸리티 패널이 열린다. 기본 먹이 화면에서는 텍스트 입력란으로, 개발 포트 화면에서는 화면 선택 버튼으로 포커스가 이동한다. 고양이를 다시 클릭하거나 패널의 닫기 버튼·Esc를 누르면 닫힌다. 키보드로 고양이에 포커스를 둔 경우 Enter·Space로도 열고 닫을 수 있다. 드래그하거나 투명한 픽셀을 누르면 패널은 열리지 않는다.

패널은 펫과 함께 이동하고 화면 가장자리에서는 빈 공간에 맞춰 배치된다. 다른 앱을 선택해도 자동으로 닫히지는 않는다. 입력 중인 텍스트는 패널을 닫아도 유지되지만, **먹이 주기**를 누르기 전에는 디스크에 저장되지 않는다. 상단의 **먹이·변환 / 개발 포트**로 화면을 전환하며, 기존 입력과 변환 결과는 유지된다.

## 먹이 주기와 보관함

- 텍스트를 입력하거나 붙여넣고 **먹이 주기**를 누르면 저장한다. 텍스트를 펫의 보이는 픽셀이나 패널에 직접 드롭해도 저장된다.
- 사진 등 일반 파일을 펫이나 패널에 드롭하거나 **파일·사진 선택**으로 고른다. 클립보드의 이미지도 붙여넣어 저장할 수 있다. 폴더·심볼릭 링크는 지원하지 않는다.
- 텍스트는 UTF-8 기준 1MB, 파일은 개당 25MB, 한 번에 10개까지 지원한다. 빈 텍스트·크기 초과·읽기/쓰기 오류를 안내한다. 여러 파일 중 일부가 실패하면 성공한 파일은 보관하고 실패 항목을 표시한다.
- 파일은 원본을 이동하거나 변환하지 않고 복사한다. 같은 이름의 파일도 별도 항목으로 저장한다. 저장 성공 뒤에만 펫이 먹이를 받아 씹고, 하트를 띄운 뒤 대기로 돌아간다. 동작 줄이기 설정에서는 정적인 성공 표정으로 표시한다.
- 보관함에서 텍스트를 다시 입력란으로 불러오거나, 파일을 기본 앱으로 열거나, 저장 폴더에서 확인할 수 있다. 파일은 저장할 때 자동으로 열지 않는다.

저장한 먹이는 Electron 사용자 데이터 폴더(`app.getPath('userData')`)의 `food/` 아래에 **로컬 파일로 보관되며 재실행 후에도 유지**된다. 패널의 **폴더 열기**로 접근할 수 있다. 각 항목은 고유 ID 폴더 아래 `meta.json`과 `content/` 원본 파일로 구성된다. 임시 저장이 끝난 항목만 목록에 나타나며, 손상되거나 파일이 없어진 항목은 목록에서 제외한다. 외부 서버에는 전송하지 않는다.

위치는 Electron의 사용자 데이터 폴더(`app.getPath('userData')`) 아래 `pet-position.json`에 저장된다. 저장 파일이 없거나 손상되면 기본 위치에서 시작한다. 저장에 실패해도 펫은 계속 동작하며 실행 터미널에 오류를 기록한다.

종료하려면 고양이를 우클릭해 **BytePet 종료**를 선택하거나 앱 메뉴에서 종료한다. 시스템의 동작 줄이기 설정을 사용하면 고양이는 정지 상태로 표시된다.

## JWT 해독

텍스트 입력란에 JWT를 붙여넣거나 보관함의 **텍스트 불러오기**로 복원한 뒤 **JWT 해독**을 누른다. 자동으로 인식되지 않으면 **입력 형식 → JWT**를 선택한다. `Bearer ` 접두사와 앞뒤 공백도 처리한다. Header와 Payload를 들여쓰기한 JSON으로 표시하며, 입력을 수정하거나 다른 텍스트를 불러오면 이전 결과를 지운다.

- `exp`를 Unix 초로 읽어 UTC 만료 시각과 만료 여부를 표시한다. 결과를 열어 두면 컴퓨터 시각 기준으로 상태를 갱신한다. `exp` 없음과 잘못된 값도 구분한다.
- **서명 검증은 수행하지 않는다.** 화면에 항상 서명 미검증 여부를 표시하고, `alg: none`은 서명 없음으로 표시한다. 만료되지 않았다는 표시는 토큰의 진위나 사용 가능 여부를 보증하지 않는다.
- 빈 입력, 1MB 초과, 잘못된 Base64URL·UTF-8·JSON·토큰 구조를 안내한다. 암호화된 JWT(JWE)는 지원하지 않는다.
- 해독은 로컬에서만 수행하며 토큰을 전송하거나 자동 저장하지 않는다. 보관하려면 별도로 **먹이 주기**를 누른다. 해독한 Header·Payload·전체 결과를 복사할 수 있다.

형식과 만료 처리 기준: [JWT 규격 RFC 7519](https://www.rfc-editor.org/rfc/rfc7519.html), [JWS 규격 RFC 7515](https://www.rfc-editor.org/rfc/rfc7515.html).

## JSON 정리

텍스트 입력란에 JSON을 넣거나 보관함에서 불러온 뒤 **JSON 정리**를 누른다. 자동으로 인식되지 않으면 **입력 형식 → JSON**을 선택한다. 결과에 2칸 들여쓰기를 적용하며 원문 입력은 유지한다. 객체·배열 외에 문자열·숫자·불리언·null도 지원한다.

- 숫자를 JavaScript 값으로 변환하지 않고 원문 토큰의 공백만 정리한다. 큰 정수, 지수 표기, 키 순서와 중복 키, 문자열 이스케이프가 유지된다.
- 문법 오류는 원문의 **줄·열 번호(1부터 시작)**와 설명을 표시한다. **오류 위치로 이동**을 누르면 입력란의 해당 문자를 선택한다. 입력 끝의 오류는 마지막 커서 위치로 이동한다. 열은 Unicode 코드 포인트 기준이다.
- 주석·마지막 쉼표 등 표준 JSON에 없는 문법은 오류로 안내한다. 입력은 UTF-8 기준 1MB, 중첩은 128단계, 정리 결과는 4,194,304 UTF-16 코드 단위까지 지원한다.
- 로컬에서만 정리하며 자동 저장하거나 전송하지 않는다. 입력 수정·보관함 불러오기·저장 후 입력 초기화 시 결과를 지운다. JWT와 JSON은 선택한 도구의 결과만 표시한다. **결과 복사**로 들여쓰기한 내용을 클립보드에 복사한다.

문법 기준: [JSON 규격 RFC 8259](https://www.rfc-editor.org/rfc/rfc8259.html).

## 입력 형식 자동 선택

**입력 형식**의 기본값은 **자동**이다. 입력·붙여넣기·보관함 불러오기 때 JWT/JSON 후보를 선택하고 실행 버튼을 **JWT 해독** 또는 **JSON 정리**로 바꾼다. 자동 선택은 도구 선택만 수행하며, 버튼을 누르면 실제 해독·정리와 오류 안내를 진행한다. 입력이 자동 저장되지는 않는다.

- JSON 객체·배열·문자열·숫자·true·false·null 형태를 인식한다. JSON 문자열 안에 들어 있는 JWT는 JSON으로 처리한다.
- `Bearer` 접두사가 있거나 점으로 구분된 3개/5개 부분 중 Header가 JSON 객체 형태인 입력은 JWT 후보로 선택한다. 잘못된 토큰이나 지원하지 않는 JWE도 실행 시 구체적인 안내를 받을 수 있다.
- 일반 메모·파일명·URL 등 판별하지 못한 입력은 **JWT** 또는 **JSON**을 직접 선택한다. 직접 선택한 형식은 입력 수정·보관함 불러오기·패널 재열기 후에도 유지된다. **자동**을 다시 선택하면 현재 입력으로 재판별한다. 앱 재시작 시에는 자동으로 시작한다.
- 자동 모드에서 빈 입력·판별 불가·1MB 초과 입력은 실행 버튼을 비활성화한다. 한글 등 조합 입력 중에는 실행을 막고 조합 완료 후 판별한다. 입력이나 형식 변경 시 이전 결과를 지운다.
- 펫·패널에 드롭해 보관한 텍스트는 보관함에서 불러와 처리한다. 파일 저장·열기 동작은 기존과 같다.

## 결과 복사와 변환 반응

- JSON은 **결과 복사**, JWT는 **Header 복사 / Payload 복사 / 전체 복사**를 제공한다. JWT 전체 복사는 `{ "header": …, "payload": … }` 형태의 JSON이다. 만료 안내나 서명 검증 문구는 복사 내용에 포함하지 않는다.
- 복사 버튼을 눌렀을 때만 클립보드에 쓰고 완료·실패를 표시한다. 변환 오류가 있거나 결과를 지우면 복사할 수 없다. 복사 실패 시 결과를 유지해 다시 시도할 수 있다. 복사는 최대 4,194,304 UTF-16 코드 단위를 지원한다.
- 변환 결과는 즉시 표시하며 펫은 **씹기(650ms) → 성공/실패 표정(1.1초) → 대기** 순서로 반응한다. 성공하면 하트·반짝임, 실패하면 당황한 표정·물음표를 표시한다. JWT 성공 반응은 해독 완료를 뜻하며 서명 검증이나 토큰 유효성을 보증하지 않는다.
- 동작 줄이기 설정에서는 각 단계에 정적인 표정을 사용한다. 연속 실행이나 새 먹이 저장이 들어오면 가장 최근 동작을 재생한다. 입력 변경·형식 변경·결과 닫기 후에는 이전 복사 요청의 늦은 응답이 새 화면에 표시되지 않는다.
- 변환이나 복사는 보관함에 자동 저장하지 않는다. 클립보드 읽기·감시·히스토리 기능은 제공하지 않는다.

## 개발 포트 목록

패널 상단의 **개발 포트**를 누르면 현재 컴퓨터의 **TCP 리스닝 포트·PID·프로세스 이름·IPv4/IPv6 바인딩 주소**를 조회한다. 현재는 macOS를 지원한다. 같은 PID와 포트의 여러 주소는 한 항목으로 묶고 포트 번호, PID 순으로 정렬한다. `*`는 모든 인터페이스를 의미한다. 개발용으로 자주 쓰는 포트 외에 현재 권한으로 조회 가능한 다른 리스닝 포트도 표시한다.

- 포트 화면 진입·해당 화면으로 패널 재열기·**새로고침** 때 조회한다. 상시 폴링하지 않으며 먹이 화면에 머물 때는 조회를 시작하지 않는다.
- 조회 중·결과 없음·실패·일부 결과 가능성을 구분하고 마지막 조회 시각을 표시한다. 새로고침에 실패하면 기존 목록을 유지하면서 이전 결과임을 안내한다. 조회 가능한 범위는 운영체제와 현재 사용자 권한에 따라 다르다.
- 포트 화면에서 붙여넣거나 드롭한 내용은 먹이로 저장하지 않는다. **먹이·변환**으로 돌아가면 기존 입력·결과를 계속 사용할 수 있다.
- macOS의 `/usr/sbin/lsof`를 고정 인수로 실행해 로컬 소켓 정보를 읽는다. DNS·서비스명 조회와 셸 실행을 사용하지 않으며, 한 번의 조회는 5초·출력 2MB로 제한한다. 중복 조회는 공유하고 앱 종료 시 진행 중인 조회를 취소한다. 목록은 디스크에 저장하지 않는다.

## 포트 주소 열기

포트 항목의 **브라우저로 열기**를 누르면 표시된 HTTP 주소를 기본 브라우저로 연다. 주소는 조회된 바인딩 정보에서 정한다. 루프백 주소를 우선하며 `*`·`0.0.0.0`은 `127.0.0.1`, IPv6의 `*`·`::`는 `[::1]`로 연다. 특정 인터페이스에만 바인딩된 포트는 그 IP를 사용한다.

- HTTP를 기본으로 사용하며 프로토콜을 자동 탐지하거나 서버에 미리 접속하지 않는다. HTTPS 전용 서버와 데이터베이스 같은 웹 서버가 아닌 포트는 브라우저에서 연결되지 않을 수 있다.
- 브라우저 실행 요청 중 중복 열기를 막고 실패하면 재시도할 수 있다. 완료 안내는 기본 브라우저에 열기를 요청했다는 뜻이며 서버 응답 성공을 보장하지 않는다. 종료된 서버는 **새로고침**으로 목록에서 제거한다.
- 패널은 조회된 PID·포트만 전달한다. 메인 프로세스가 마지막 성공한 조회 결과에서 주소를 찾으며 임의 URL이나 외부 프로토콜을 전달받아 열지 않는다. 브라우저에서 지원하지 않는 주소는 열기 버튼을 비활성화한다.
- 기본 브라우저 연동은 Electron의 [shell.openExternal](https://www.electronjs.org/docs/latest/api/shell#shellopenexternalurl-options)을 사용한다.

다음 작업은 선택한 프로세스 종료(F12)다. 이 구현은 Electron 기반 MVP이며 PRD의 Tauri 메모리·설치 용량 목표를 충족했다고 간주하지 않는다.

## 검증

```sh
npm test
npm run test:desktop
```

데스크톱 테스트는 실제 Electron GUI를 실행한다. 디스플레이가 있는 환경에서 실행해야 한다. 테스트마다 임시 사용자 데이터 폴더를 사용하므로 사용자의 저장 위치를 변경하지 않는다. 드래그와 재실행 복원, 저장 파일 손상, 종료 직전 저장, 포인터 캡처 해제를 검사한다. 다중 모니터 좌표는 단위 테스트로, 실행 중 화면 변경은 모의 화면 이벤트로 검증한다.

F03 자동 테스트는 투명 픽셀 판정, 정지한 커서 아래에서의 애니메이션 변화, 드래그·메뉴 중 입력 유지, 재진입과 페이지 재로드를 검사한다. 커서 위치를 모의로 지정하고 실제 Electron 입력 전환 API 호출을 확인한다. macOS 네이티브 마우스 이벤트로 뒤쪽 테스트 창에 클릭이 전달되고, 펫 픽셀에서 클릭·드래그·우클릭이 동작하는 것도 별도로 확인했다. Windows/Linux와 실제 다중 모니터 환경은 아직 검증하지 않았다.

F04 테스트는 펫 클릭 토글, 네이티브 패널 포커스와 텍스트 입력, Esc·닫기 버튼, 재열기 시 메모 유지, 드래그 구분, 빠른 토글, 화면 안 배치·펫 이동 추종, 앱 종료 시 패널 정리를 확인한다. 패널 스크린샷은 `test-results/f04-panel.png`에 저장한다.

F05는 텍스트 원문·사진 파일 바이트 보존, 중복 이름, 재실행 복원, 파일 선택, DOM 드롭·붙여넣기 이벤트, 클립보드 이미지, 부분 성공, 용량 제한, 저장소 오류와 입력 보존을 검증한다. 저장 성공 시 먹는 애니메이션과 동작 줄이기 설정도 검사한다. 자동 테스트는 임시 보관함을 사용하며 Finder 드래그나 운영체제 클립보드 자체를 조작하지 않는다. `test-results/f05-panel.png`, `test-results/f05-eating.png`에 화면을 저장한다.

F06은 Unicode·Bearer 입력, 잘못된 인코딩·객체 구조·크기 제한, 만료 경계·누락·오류, 서명 없음, 화면에서의 만료 상태 갱신, 보관함 연동과 입력 변경 시 결과 초기화를 검증한다. HTML 형태의 Payload도 텍스트로 표시하며, 해독만으로 저장·HTTP 요청이 발생하지 않는지 확인한다. 화면은 `test-results/f06-jwt.png`에 저장한다.

F07은 들여쓰기와 원문 토큰 보존, 기본 JSON 파서와의 문법 수용 일치, Unicode·줄바꿈별 오류 위치, 입력·중첩·출력 제한을 검증한다. 실제 Electron에서 보관함 연동, JWT/JSON 전환, 오류 위치 선택, 긴 입력의 스크롤, 실패 후 복구와 원문 유지도 확인한다. 화면은 `test-results/f07-json.png`, `test-results/f07-error.png`에 저장한다.

F08은 JSON의 모든 최상위 값, JWT·Bearer·JWE 후보, 일반 텍스트 구분과 UTF-8 크기 제한을 검증한다. Electron에서 자동 선택된 도구의 실행, 수동 선택 유지·자동 복귀, 오류 처리, 보관함·붙여넣기·저장 후 상태 초기화와 조합 입력을 검사한다. 붙여넣기·조합은 DOM 이벤트로 모의하며 운영체제 IME 자체를 조작하지 않는다. 화면은 `test-results/f08-auto.png`에 저장한다. 회귀 검증에서 발견한 앱 종료 시 렌더러 상태 전송 오류를 수정하고, 종료 과정의 예외도 검사한다.

F09는 클립보드 쓰기 완료 대기·오류·동시 요청·IPC 발신자와 크기 제한, 반응 단계와 오래된 타이머 취소를 검증한다. Electron에서 JSON/JWT를 실제 시스템 클립보드에 복사해 내용을 확인하고, 테스트 전 클립보드의 전체 형식을 보관했다가 테스트 내용이 그대로 남아 있을 때 복원한다. 복사 실패·지연 응답은 모의하며, 펫의 씹기·성공/실패·대기 및 동작 줄이기와 연속 실행을 검사한다. 화면은 `test-results/f09-copy.png`, `test-results/f09-success.png`, `test-results/f09-failure.png`에 저장한다.

F10은 포트/PID별 묶기·정렬, IPv4/IPv6, 잘못된 레코드, 빈 결과·경고·실패, 고정 실행 인수·제한, IPC 권한·중복 조회·종료 취소를 검증한다. 실제 임시 TCP 서버를 열어 포트·PID·이름·주소를 확인하고 서버 종료 후 새로고침에서 사라지는 것을 검사한다. UI의 지연·빈 목록·부분 결과·실패·재시도는 모의하며 입력 보존과 안전한 프로세스 이름 표시도 확인한다. 화면은 `test-results/f10-ports.png`, `test-results/f10-empty.png`에 저장한다.

F11은 IPv4/IPv6·전체 인터페이스 주소 변환, 잘못된 주소·포트 거부, 마지막 조회 결과와 IPC 권한, 중복 열기와 실패 후 재시도를 검증한다. Electron에서는 실제 임시 TCP 서버의 행을 키보드·버튼으로 열어 기본 브라우저 실행 API에 전달되는 URL을 확인한다. 브라우저 실행 경계는 모의해 사용자 브라우저에 탭을 만들지 않는다. 새로고침·화면 전환 중 완료가 새 행이나 입력 포커스에 영향을 주지 않는지 확인한다. 화면은 `test-results/f11-open-port.png`에 저장한다.
